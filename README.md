# Sketchett · سكيتشيت

**نسخة خاصة بالشركة — تحتاج مفتاح تفعيل لكل جهاز.**
Private company edition: every computer needs an activation key.

## التنصيب · Install
1. حمّل `Sketchett-x.y-Setup.exe` من صفحة **[Releases](../../releases/latest)** ونصّبه.
   Download `Sketchett-x.y-Setup.exe` from **[Releases](../../releases/latest)** and install it.
2. افتح البرنامج، انسخ **رمز الجهاز**، ودزه لمسؤول البرنامج.
   Open Sketchett, copy the **computer code** and send it to the administrator.
3. الصق **مفتاح التفعيل** اللي يوصلك واضغط **تفعيل**.
   Paste the **activation key** you receive and press **Activate**.

التحديثات توصل وحدها للأجهزة المفعّلة.
Updates arrive automatically on activated computers.

Requirements: Windows 10/11 64-bit with Microsoft Edge WebView2.
